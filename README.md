# KDR Restaurant

A modern and responsive restaurant website featuring an elegant dark theme with gold accents.

## About The Project

KDR Restaurant is a website project designed to showcase a modern restaurant experience with an interactive menu and user-friendly interface.

## Features

- Responsive website design
- Interactive food menu
- Menu categories and filtering
- Shopping cart
- WhatsApp ordering
- Reservation section
- Indonesian and English language support

## Technologies

- HTML5
- CSS3
- JavaScript
